## 🕹️ Project Overview

Bean Slayer is a DOOM-inspired first-person shooter created for my first-year Game Creation assessment. The prototype brings together combat, enemy AI, player movement and a sci-fi laboratory environment in Unreal Engine 5.

## 🛠️ Key Technical Features

* **Player controls:** Enhanced Input actions for movement, looking, jumping, dashing, attacking, aiming, interaction and weapon selection.
* **Enemy AI:** Blueprint enemy variants, including ranged, heavy and zombie enemies, supported by NavMesh navigation.
* **Health and damage:** A Blueprint health component and damage interface for gameplay interactions.
* **User interface:** UMG widgets for health, shields, ammunition and dash, alongside menus, a tutorial screen and an ending screen.
* **Event-driven gameplay:** Blueprint visual scripting and interfaces used to connect gameplay systems and world interactions.

## 💻 Technical Specs
* **Engine:** Unreal Engine 5.5
* **Language:** Blueprint Visual Scripting
* **Core Systems:** UMG (HUD), AI Navigation (NavMesh), Enhanced Input, Event-Driven Logic
* **Tools:** Maya, Adobe Substance 3D Painter, GitHub, Trello
